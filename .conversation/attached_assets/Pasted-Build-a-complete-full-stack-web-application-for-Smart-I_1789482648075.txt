Build a complete full-stack web application for Smart India Hackathon 2026 Problem Statement ID 26032.

PROBLEM:
Farmers often face long waiting times, lack of information regarding procurement schedules, and uncertainty about procurement status.

EXPECTED SOLUTION:
Develop a platform that:
1. Enables farmer registration and slot booking.
2. Provides real-time queue management.
3. Sends SMS/app-style notifications.
4. Tracks procurement and payment status.
5. Reduces congestion and waiting time at procurement centres.

DATABASE REQUIREMENTS:
- Add foreign keys.
- Add useful indexes.
- Add created_at timestamps.
- Add reasonable constraints.
- Prevent duplicate slot bookings when capacity is reached.
- Prevent two active bookings for the same farmer at the same time.
- Use Row Level Security where practical.
- Farmers should only see their own data.
- Centre admins should only manage their assigned centre.
- Super admins can access all data.
